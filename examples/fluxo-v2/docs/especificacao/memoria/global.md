# Memória global — invariantes

Projeto fictício: login local para estudo da metodologia. Idioma de interface: português brasileiro.
- Segredos e senhas nunca podem aparecer em logs, exemplos ou commits.
- Toda autenticação deve tratar credenciais inválidas sem indicar se o usuário existe.
- Não construir cadastro, cobrança ou dashboard nesta sprint.
- Registrar decisões de contrato antes de tarefas paralelas.
- Uma task é concluída somente com commit e evidências de testes; a sprint depende de aprovação humana.
- Task: testar localmente; sprint: testar fluxos afetados; checkpoint: suíte completa. Cobertura mínima de 80% onde medida.
