# Memória de domínio — autenticação

Autenticação local, sem provedor externo. Contrato detalhado em contratos/login.md, fonte de verdade.
O backend não deve conhecer detalhes visuais. Mensagens públicas não devem permitir enumeração de usuários.
Sessões devem ter expiração definida na etapa de implementação. Para projeto real, documentar hash de senhas, proteção contra força bruta e persistência efetiva antes de executar as tasks.
