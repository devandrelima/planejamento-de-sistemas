# P01 — Mapa humano: contrato e serviço

**Objetivo da sprint:** login utilizável, demonstrado antes de avançar.

**Task T01:** estabelecer contrato interno e testes. **Task T02:** implementar serviço de autenticação seguindo o contrato.

O humano seleciona o mapa e orienta os agentes a executar tasks isoladas pelo comando fluxo.py. Tasks não devem receber o prompt completo como contexto; cada pacote inclui somente memória global, domínio e contrato.

Saída esperada: backend verificável e contrato estável para trabalho de interface em paralelo com T02.
