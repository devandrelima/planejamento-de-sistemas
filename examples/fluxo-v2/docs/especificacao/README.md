# Especificação v2 — Sprint 01

Este é um exemplo de **planejamento**. Os prompts são mapas para uma pessoa selecionar e entregar a um agente. As tasks JSON são as instruções executáveis.

| Sprint | Prompt-mapa | Tasks | Entrega |
|---|---|---|---|
| S01 | [P01](sprints/S01/P01.md) | T01, T02 | Contrato e serviço de autenticação |
| S01 | [P02](sprints/S01/P02.md) | T03, T04 | Tela, integração e avaliação |

A próxima sprint fica bloqueada até aceite humano, mesmo quando todas as tasks estão concluídas. Usar a ferramenta fluxo.py para carregar somente a memória de cada task.
