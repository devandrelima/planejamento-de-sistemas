# Contrato de login — demonstração

Fluxo: fornecer usuário e senha; receber sucesso com informação de sessão ou erro genérico de credenciais. Senha não aparece em resposta nem log.
Para execução real, escolher e registrar: framework, formato do payload, sessão/cookie, hash de senha, persistência, tempo de expiração, rate limiting e comandos concretos de teste. Não improvisar estas decisões dentro de tasks sem atualizar o contrato e invalidar pacotes dependentes.
